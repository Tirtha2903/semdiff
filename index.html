How it works

01

Parse

Reads every function from the assembly. Names are ignored.

02

Execute

Runs each function on edge cases and random inputs.

03

Observe

Records calls, memory writes outside the stack, and return values.

04

Match

Pairs functions across builds by how they behave.

05

Prove

Classifies each change. The exploit finder locates the exact input that triggers it.

06

Explain

Gemma 4 investigates and explains, grounded in the engine's facts.

An analyst powered by Gemma 4

The engine proves what changed. Gemma 4 thinks, calls tools and reads screenshots, running on your own machine.

Thinking mode

Reasons through a change before it answers.

Function calling

Calls run_function and compare to test its own theories.

Vision

Reads assembly straight from a Ghidra or IDA screenshot.

Local and open
